# GEO2R_FastingAnalysis

Judul: Analisis transkriptomik metabolisme adaptasi tubuh terhadap puasa 24 jam

Sinopsis Analisis:
Analisis gen yang berperan dalam metabolisme tubuh setelah berpuasa, menggunakan dataset GSE55924 dan dianalisis dengan GEO2R dengan parameter adjP-value < 0.05 dan |log2FC| ≥ 1. 

Hasil analisis dapat diperoleh pada file laporan 41_Christabella Michelle Kwan_Week 2, sedangkan file GSE55924.top.table.tsv adalah tabel berisi semua gen yang terdeteksi secara lengkap dan diurutkan dari adjpvalue terkecil
